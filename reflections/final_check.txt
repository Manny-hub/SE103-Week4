What a pull request asks teammates to do:
A pull request asks teammates to review my changes before they are merged into the main branch. It gives them an opportunity to check the work, provide feedback, and identify any problems.

Why branches and pull requests are used together:
Branches allow me to work on changes separately from the main branch. A pull request then provides a way for those changes to be reviewed before they are merged into main.

One thing that confused me in this project and how I solved it:
One thing that confused me was understanding the difference between a commit and a push. I learned that a commit records changes in my local Git repository, while a push sends those commits to GitHub. I solved this by practicing the commands and checking the repository history with Git commands. This helped me understand how local changes are recorded and then transferred to the remote repository.
